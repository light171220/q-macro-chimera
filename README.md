# Q-Macro Chimera

A Frankenstein workbench fusing classical Monte Carlo risk models with quantum circuits, verified by Kiro Property-Based Testing (PBT).

Built for **Kiroween 2026** (*Frankenstein* Category) using **Kiro** spec-driven development.

> Note: The `/.kiro` directory is intentionally committed to this repository to document specs, hooks, and steering used during development.
